# Local typefaces

Unmodified Figtree and Newsreader variable TrueType fonts from the Google Fonts
repository. Each font ships with its original SIL Open Font License in this
directory. `provenance.json` records the downloaded source URL, byte length and
SHA-256. No browser font requests go to Google or another external host.

The Ozzie logo and favicon in the parent directory are unchanged owner-supplied
artwork.
