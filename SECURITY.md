# Security

## Reporting a problem

Please report security problems privately, not in a public issue.

- Use GitHub's private reporting on this repository: **Security** →
  **Report a vulnerability**.
- Or write to the security address listed at https://ozzie.church/privacy.

Please include what you found, how to reproduce it, and which version or
commit you used. Don't include a real person's details: use fictional data.
You will get a reply as soon as we can, normally within a few working days.
Ozzie is an early project maintained by a very small team, so there is no
bug bounty.

## What matters most

Reports in these areas are especially welcome:

- any way Ozzie could change or send something in Planning Center or another
  church system other than the one change a person confirms on screen (adding
  one person to an open role as unconfirmed, and taking them off again), or
  make that change without the confirmation, for another church, or with
  changes turned off;
- any way a name Ozzie read, a contact detail or a background-check fact
  could reach an AI model or another app;
- any way text inside church data (an email, a note, a plan title) could be
  followed as an instruction;
- sign-in, token storage in the macOS Keychain, and the connection between
  the Mac app and ozzie.church.

## Supported versions

Only the latest commit on the main branch is supported.
